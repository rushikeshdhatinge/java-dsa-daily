# Contributing

## Naming
- Folders: lowercase-kebab-case, e.g. `valid-anagram`
- Java class: always `Solution` in `Solution.java`
- Only edit files inside **your own** `members/<your-name>/` folder

## Per-problem files
- `Solution.java` – start from `templates/Solution.java`
- `README.md` – start from `templates/PROBLEM_README.md` (link, approach, complexity)

## Commit messages
```
[topic] problem-name - your-name
```
Example: `[strings] valid-anagram - rushikesh`

## Workflow
- Small team: push directly to `main`.
- Larger team: open a pull request and ask one teammate to review.
