# java-dsa-daily

A shared repository for **daily accountability**: every member solves at least one DSA problem in Java each day and pushes it here.

## Rules
1. Solve **one problem per day** (LeetCode, GFG, HackerRank, or a classic like palindrome/anagram).
2. Put it in `members/<your-name>/<topic>/<problem-name>/`.
3. Commit and push the same day. The commit is your check-in.
4. Add one line to `LOG.md`.

## Structure
```
members/<name>/<topic>/<problem>/
    Solution.java
    README.md
templates/      starter files and an example problem
scripts/        helper scripts (add a new member, etc.)
```

## Topics
arrays, strings, hashing, linked-list, stack-queue, trees, graphs, recursion-backtracking, dp, sorting-searching, math
