# Perfect Number

**Topic:** math

## Problem
Given a number, check whether it is a perfect number. A perfect number is one whose divisors (excluding itself) add up to the number itself.

## Examples
| Input | Output |
|---|---|
| 28 | Perfect |
| 12 | Not perfect |
