# Linear Search

**Topic:** arrays

## Problem
Given an array and an element, print the index at which the element is found.

## Examples
| Input | Output |
|---|---|
| {5, 8, 2, 9}, find 2 | index 2 |

## ADT
Data - int arr[],index,num;boolean isfound;
Methods -  find();

## Complexity
- Time: O(n)
- Space: O(1)
