# Count Positive, Negative and Zero

**Topic:** arrays

## Problem
Given an array, count how many elements are positive, negative and zero.

## Examples
| Input | Output |
|---|---|
| {3, -1, 0, 5, -8, 0} | 2, 2, 2 (positive, negative, zero) |

## ADT
Data - int arr[];int P,N,Z
Methods -   find();

## Complexity
- Time: O(n)
- Space: O(1)
