# Power Using Loop

**Topic:** math

## Problem
Given a number x and a power n, find x to the power n using a loop. Do not use Math.pow.

## Examples
| Input | Output |
|---|---|
| x = 2, n = 5 | 32 |

## ADT
Data -  Int Number,Power,Result
Methods - Process();

## Complexity
- Time: O(n)
- Space: O(1)
